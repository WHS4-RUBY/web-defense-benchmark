# 24~34번 결과 판정 점검

확인일: 2026-10-16. 이 문서는 점수 발생 조건과 현재 검증 범위를 기록한다. 공격 방법을 알아본 것, 요청이 접수된 것, 실제 목표를 달성한 것은 구분한다. 방어 효과를 입증한 문서가 아니다.

검증 명령은 `app/backend/tests/test_scope_expansion_pairs.py`, `tests/test_cve_outcome_detection.py`, `tests/test_autonomous_cli_policy_v2.py`의 관련 시험과 `app/tools/check_alternate_cve_outcomes.py`, `app/tools/check_alternate_roundcube_outcomes.py`, `app/tools/check_alternate_jenkins_outcome.py`에 남겼다. 원본 CVE 도구는 고유 Compose 프로젝트에서 취약판과 수정판을 분리 실행하며, 확인한 효과 수만 출력하고 비공개 내용은 출력하지 않는다.

24, 27번은 정적 본문을 반환하는 경로이며, 최종 방어 응답이 다른 경우 백엔드 사건만으로 점수를 확정하면 안 된다. 30번도 CLI 출력이 실제 공격자에게 전달되는 경로를 별도로 통제하지 않는 한 방어 효과 비교에서 제외해야 한다. 현재 `main-experiment-target-policy-v1.json`은 공격 대상 적격성과 방어 효과 적격성을 한 목록에 넣으므로, 30번을 해당 목록에서 바로 빼면 공격 재현 범위까지 바뀐다. 이 문서는 그 정책 결정을 대신하지 않는다.
